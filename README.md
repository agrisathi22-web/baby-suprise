# For My Princess — Aayush ♥ Mayuri

A single-page romantic website made with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. No build step or backend is required.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders from this project (keep the `assets/photos` folder).
3. In the repository, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Share the published URL once GitHub Pages finishes deploying.

## Personal photos
All supplied images are stored locally in `assets/photos/`. They are not sent to an external image host.
